# Data

Download the dataset from Kaggle:
https://www.kaggle.com/clmentbisaillon/fake-and-real-news-dataset

Place the following files here:
- `True.csv` — Factual news articles (~21,000 rows)
- `Fake.csv` — Fake news articles (~23,000 rows)

`final_data.csv` is auto-generated when you run the notebook.
