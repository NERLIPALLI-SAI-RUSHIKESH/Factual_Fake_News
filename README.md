## 🧩 Problem Statement

Misinformation spreads rapidly online and is difficult to detect manually. This project builds an automated NLP pipeline that reads a news article's headline and body, and classifies it as **Fake (0)** or **Factual (1)** — helping flag potentially misleading content at scale.

---

## 📊 Dataset

| Property | Detail |
|---|---|
| Total articles | 44,898 |
| Fake articles | 23,481 (52.3%) |

| Features used | `title` + `text` (combined) |

## 🔬 Full Pipeline

### 1. Data Loading & Cleaning
- Loads and merges `True.csv` + `Fake.csv` with labels
- Removes nulls, duplicate articles, and very short texts (< 30 chars)
- Strips extra whitespace and normalises text

### 2. Feature Engineering
- `text_length` — character count of article body
- `title_length` — character count of headline
- `word_count` — total words per article
- `unique_words` — vocabulary richness metric

### 3. Exploratory Data Analysis (EDA)
- ✅ Class balance — count plot + pie chart
- ✅ Text length distributions (histogram with mean/median lines)
- ✅ Average text length, title length & word count by label
- ✅ Word count box plot (Fake vs Factual)
- ✅ Vocabulary richness violin plot
- ✅ Top 10 unigrams and bigrams per class

### 4. NLP Analysis
- ✅ POS tagging frequency (spaCy, sample of 500 articles)
- ✅ Named Entity Recognition — top 10 entities in Fake news
- ✅ Named Entity Recognition — top 10 entities in Factual news

### 5. Text Preprocessing
- Combine `title` + `text` → `content`
- Lowercase, remove punctuation, collapse whitespace
- Tokenize → remove stopwords → lemmatize (NLTK)

### 6. Vectorization
- TF-IDF with `max_features=50,000` and `ngram_range=(1, 2)`
- Fit on training set only (no data leakage)

### 7. Model Training & Evaluation
- 6 classifiers trained with 80/20 stratified split
- Metrics: Accuracy, F1-Score, train time
- Confusion matrix + full classification report for the best model

### 8. Deployment
- Streamlit app with real-time prediction (headline + article body input)

## ⚙️ Installation & Setup

```bash
# 1. Clone the repository
git clone https://github.com/NERLIPALLI-SAI-RUSHIKESH/Factual_Fake_News.git
cd Factual_Fake_News

# 2. Install dependencies
pip install -r requirements.txt

# 3. Download NLTK data
python -c "import nltk; nltk.download('punkt'); nltk.download('stopwords'); nltk.download('wordnet')"

# 4. Download spaCy model
python -m spacy download en_core_web_sm
```

## ▶️ How to Run
### Quick Start (No Training Required)

You only need two things to run the app:

1. Download the `model/` folder and `app.py`
2. Place them together in the same directory like this:

```
your-folder/
├── app.py
└── model/
    ├── best_model.pkl
    ├── tfidf.pkl
    └── best_model_name.txt
```

Then run:

```bash
streamlit run app.py
```

That's it! The app will load the pre-trained model and vectorizer automatically and start serving predictions in your browser.

> No need to run the notebook, download datasets, or train any models from scratch.
